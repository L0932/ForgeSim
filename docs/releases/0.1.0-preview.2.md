# ForgeSim 0.1.0-preview.2

Windows installer preview of the ForgeSim Sandbox.
A portable ZIP remains available.

## Changes

- Added a Windows installer with Start Menu shortcuts and an uninstaller.
- Added detection of existing installations during replacement installation.
- Added Windows Debug and Release build and headless-test validation through GitHub Actions.
- Fixed filesystem path comparisons in scene-save tests.

## Requirements

- Windows x64.
- An OpenGL 4.6-capable graphics driver.

## Installation

Download and run the file ending in -Setup.exe.
Choose an installation directory and follow the installer.

The default installation directory is:

C:\Program Files\ForgeSim

Installation and uninstallation may require administrator approval.
Running ForgeSim after installation does not require administrator privileges.

The installer is unsigned. Windows may display an unrecognized-publisher
or reputation warning.

Close ForgeSim before installing a replacement version.

## Portable Package

Alternatively, extract the entire ZIP and launch ForgeSimSandbox.exe.
Keep the assets directory beside the executable.

## User Data

Default locations:

- Scenes: %LOCALAPPDATA%\ForgeSim\Scenes
- Editor layout: %LOCALAPPDATA%\ForgeSim\Settings\imgui.ini

Uninstallation preserves these user-data locations.
Explicitly selected scene-save locations remain supported.

## Known Limitations

- This is an early development preview.
- Interactive scenes currently support one shared model asset.
- Scene documents reference assets rather than embedding or copying them.
- Undo and redo currently cover gizmo transform edits.
- Shadows and additional showcase rendering effects remain in development.
- Physics, runtime tool interactions, and VR are not yet available.
- Purchased workshop assets are not included.

## Reporting Problems

Include the ForgeSim version, Windows version, graphics hardware,
driver version, reproduction steps, and relevant console output.
