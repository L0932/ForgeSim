# ForgeSim 0.1.0-preview.1

First downloadable Windows preview of the ForgeSim Sandbox.

## Included Features

- glTF metallic-roughness PBR rendering.
- Base-color, normal, metallic-roughness, occlusion, and emissive textures.
- Image-based lighting, an environment background, exposure, and tone mapping.
- Editable directional, point, and spot lights.
- Object and light selection and transform gizmos.
- Undo and redo for gizmo transform edits.
- A docked Scene viewport, hierarchy, Inspector, and debug controls.
- Scene-document saving and loading through native Windows file dialogs.
- Persistent editor layout stored in the user's application-data directory.
- A bundled PBR material gallery and HDR environment.

## Running

Extract the entire ZIP and launch ForgeSimSandbox.exe.

Keep the assets directory beside the executable.

The current renderer requires an OpenGL 4.6-capable graphics driver.
See README.md for resource paths and troubleshooting.

## Known Limitations

- This is an early development preview.
- Interactive scenes currently support one shared model asset.
- Scene documents reference assets rather than embedding or copying them.
- Undo and redo currently cover gizmo transform edits.
- Shadows and additional showcase rendering effects remain in development.
- Physics, runtime tool interactions, and VR are not yet available.
- Purchased workshop assets and other optional external scenes are not included.

## User Data

Default Windows locations:

- Layout: %LOCALAPPDATA%/ForgeSim/Settings/imgui.ini
- Scenes: %LOCALAPPDATA%/ForgeSim/Scenes/

The native file dialog may restore a previously visited folder.
User-selected save locations remain supported.

## Reporting Problems

Include:

- ForgeSim version
- Windows version
- Graphics hardware and driver version
- Steps to reproduce
- Relevant console output
